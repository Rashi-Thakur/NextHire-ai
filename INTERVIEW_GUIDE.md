# Interview Explanation + STAR

## 60-second Project Pitch
I built an AI Resume Analyzer + Job Matcher to help students improve ATS scores for internship applications. Users upload a resume PDF and paste a job description. The system parses resume text, computes weighted ATS metrics, detects missing skills, generates AI recommendations, and stores analysis history securely. It includes JWT auth, responsive dashboard UI, chart-based insights, and PDF report export.

## STAR Format Example

### Situation
Many students apply with resumes that fail ATS filters due to missing keywords and weak bullet points.

### Task
Build a beginner-friendly production-style web app that evaluates resumes against job descriptions and gives clear improvement actions.

### Action
- Designed full-stack architecture (React + Express + MongoDB).
- Implemented resume PDF extraction and ATS scoring engine with weighted metrics.
- Added AI-generated feedback for summary, bullets, projects, certifications, and action verbs.
- Built secure auth, protected APIs, analysis history, and downloadable reports.
- Created modern glassmorphism dashboard with charts and dark mode.

### Result
Delivered a complete deployable product that gives structured, actionable feedback in seconds and demonstrates practical skills across frontend, backend, AI integration, and system design.
